# Certificate Authority (CA) CSR fields

The `names` object in `ca-csr.json` contains X.509 distinguished-name fields:

| Field | Meaning |
| --- | --- |
| `C` | Country |
| `L` | Locality or municipality, such as a city |
| `ST` | State or province |
| `O` | Organization |
| `OU` | Organizational unit, such as the department responsible for the key |
